## Описание проекта

Многостраничный HTML/CSS-сайт учебного интернет-магазина. Реализованы:

- единая навигация между страницами;
- якорные ссылки;
- карточки товаров с бейджами «Хит» и «Новинка»;
- таблица характеристик;
- форма заявки (модальное окно + отдельная страница);
- CSS-переменные, состояния `:hover`, `:focus-visible`, `:disabled`;
- Flexbox и CSS Grid;
- базовое БЭМ-именование классов;
- позиционирование: `relative`, `absolute`, `sticky`, `fixed`, `z-index`.

## Структура проекта

- `index.html` – главная страница;
- `catalog.html` – каталог товаров с фильтрами;
- `product.html` – карточка товара с таблицей характеристик;
- `order.html` – страница оформления заявки;
- `contacts.html` – контактная информация;
- `css/style.css` – файл стилей;
- `js/main.js` – файл JavaScript (модальное окно и валидация);
- `images/` – папка для изображений;
- `README.md` – описание проекта;
- `.gitignore` – список файлов, исключённых из Git.

## Страницы проекта

- **Главная** — hero-блок, преимущества, популярные товары, модальное окно с формой.
- **Каталог** — sticky-фильтры слева, сетка карточек справа.
- **Товар** — изображение, описание, таблица характеристик, кнопка заявки.
- **Заявка** — отдельная страница с формой обратной связи.
- **Контакты** — контактная информация и ссылка на форму заявки.

## Использование Flexbox и Grid

- Flexbox — для основного меню и внутренней структуры карточек товаров;
- CSS Grid — для сетки карточек и страницы каталога с фильтрами.
