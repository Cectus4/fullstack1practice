ShopProject — учебный интернет-магазин

Многостраничный проект по дисциплине «Фронтенд и бэкенд разработка»: каталог товаров, карточка товара, оформление заявки и страница контактов. Вёрстка выполнена по методологии БЭМ с использованием Flexbox и CSS Grid.

Перейти к товарам

Преимущества проекта

  • Семантическая HTML-разметка и единая БЭМ-структура блоков;
  • Адаптивная раскладка на Flexbox и CSS Grid без фреймворков;
  • Доступные формы с HTML-валидацией и подсветкой ошибок;
  • Общий внешний файл стилей и один файл JavaScript.

Как оформить заказ

Нажмите кнопку «Заказать» в карточке товара — откроется модальное окно с формой заявки. Полную форму с выбором товара и датой связи можно открыть на странице «Оформить заказ».
